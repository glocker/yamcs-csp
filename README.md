# yamcs-csp

CSP 2.x packet support for [Yamcs](https://yamcs.org).

Yamcs 5.13 ships CSP packet processors for version 1.x. CSP 2.x changed header from 4 to 6 bytes and expanded node addresses to 14 bits, so existing processor cannot decode those packets. This project adds CSP 2.x support without requiring a Yamcs fork.

## Current state

`csp2` module contains:

- 6-byte CSP 2.x header codec;
- telemetry preprocessor with destination filtering and CRC-32C verification;
- command postprocessor with configurable CRC-32C generation;
- reference tests generated by libcsp 2.1;
- live Yamcs and libcsp interoperability checks over UDP.

Both libcsp CRC variants are covered: payload only and header plus payload. Code is implemented and tested, but `0.1.0` has not been released yet.

## Build

Requires JDK 17+, Maven 3.9+ and Yamcs 5.13.x.

```sh
mvn verify
```

This runs Java tests against committed libcsp reference vectors. It does not start Yamcs or Docker.

## Try it with Yamcs

[`examples/csp2-live`](examples/csp2-live) is a small Yamcs application kept outside root Maven reactor. It can run a quick TM/TC smoke test or build real libcsp nodes in Docker and exchange packets in both directions.

Start with [example README](examples/csp2-live/README.md).
