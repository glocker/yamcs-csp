# yamcs-csp2

CSP 2.1 packet support for [Yamcs](https://yamcs.org).

Yamcs 5.13.7 ships CSP packet processors for version 1.x. CSP 2.x changed header from 4 to 6 bytes and expanded node addresses to 14 bits, so existing processor cannot decode those packets. This project adds CSP 2.x support without requiring a Yamcs fork.

## Current state

The plugin contains:

- 6-byte CSP 2.x header codec;
- telemetry preprocessor with destination filtering and CRC-32C verification;
- command postprocessor with configurable CRC-32C generation;
- reference tests generated by libcsp 2.1;
- live Yamcs and libcsp interoperability checks over UDP.

Both libcsp CRC variants are covered: payload only and header plus payload. This is the first v 0.1.0 release.

## Build

Requires JDK 17+ and Maven 3.9+. The plugin is built and tested against Yamcs 5.13.7; other Yamcs versions have not been tested.

```sh
mvn verify
```

This runs Java tests against committed libcsp reference vectors. It does not start Yamcs or Docker.

## Use it in your Yamcs application

These steps build the plugin from source and install it into your local Maven repository.

1. Build and install the release:

   ```sh
   git clone --branch v0.1.0 https://github.com/glocker/yamcs-csp2.git
   cd yamcs-csp2
   mvn install
   ```

2. Add the dependency to the `pom.xml` of your Yamcs application, next to `yamcs-core`:

   ```xml
   <dependency>
     <groupId>io.github.glocker</groupId>
     <artifactId>yamcs-csp2</artifactId>
     <version>0.1.0</version>
   </dependency>
   ```

3. Name the classes in your link configuration: `io.github.glocker.yamcscsp.csp2.CspPacketPreprocessor` for telemetry and `io.github.glocker.yamcscsp.csp2.CspCommandPostprocessor` for commands. Options are described in [Telemetry configuration](docs/csp2.md#telemetry-configuration) and [Command configuration](docs/csp2.md#command-configuration).

The Mission Database decodes the frames. See [Decoding frames in the MDB](docs/csp2.md#decoding-frames-in-the-mdb) for how to describe them.

## Try it with Yamcs

[`examples/csp2-live`](examples/csp2-live) is a small Yamcs application kept outside the main Maven build. It can run a quick TM/TC smoke test or build real libcsp nodes in Docker and exchange packets in both directions.

Start with [example README](examples/csp2-live/README.md).
